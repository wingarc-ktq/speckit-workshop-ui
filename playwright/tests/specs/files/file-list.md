# 文書一覧表示

## 文書一覧がリストビューで表示されること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 少なくとも1件以上の文書が存在すること

### 手順

1. 文書管理ページにアクセスする
2. 文書一覧テーブルが表示されること
3. テーブルに以下の列が含まれていること：
   - チェックボックス列
   - ファイル名
   - タグ
   - アップロード日時
   - サイズ
   - アップロード者
4. 少なくとも1件以上の文書行が表示されること
5. 各文書行に以下の情報が表示されていること：
   - ファイル名（ファイルアイコン付き）
   - タグ（複数のタグチップとして表示）
   - アップロード日時（YYYY/MM/DD HH:mm形式）
   - サイズ（KB または MB）
   - アップロード者名

## 文書件数と表示範囲が正しく表示されること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 25件の文書が存在すること

### 手順

1. 文書管理ページにアクセスする
2. ページ上部に「1-20 / 25 件の文書」と表示されること
3. テーブルに20件の文書が表示されていること
4. ページネーションコントロールが表示されていること

## グリッドビューに切り替えられること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- リストビューで表示されていること

### 手順

1. 文書管理ページにアクセスする
2. リストビューが表示されていること（テーブル形式）
3. ビューモード切り替えボタンエリアでグリッドビューボタンをクリックする
4. グリッドビューに切り替わること（カード形式）
5. 各カードに以下の情報が表示されていること：
   - ファイルアイコン（種類別の色分け）
   - ファイル名
   - タグ（複数のタグチップ）
   - サイズとアップロード日時
6. グリッドビューボタンが選択状態（アクティブ）になること

## リストビューに戻せること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- グリッドビューで表示されていること

### 手順

1. グリッドビューが表示されている状態から開始する
2. ビューモード切り替えボタンエリアでリストビューボタンをクリックする
3. リストビューに切り替わること（テーブル形式）
4. リストビューボタンが選択状態（アクティブ）になること
5. 文書一覧テーブルが表示されること

## ビューモードがURLクエリパラメータで管理されること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること

### 手順

1. リストビューで表示されている状態でURLを確認する
2. URLにビューモードのクエリパラメータが含まれていないこと（デフォルト）
3. グリッドビューに切り替える
4. URLに `view=grid` クエリパラメータが追加されること
5. ページをリロードする
6. グリッドビューが維持されていること
7. リストビューに切り替える
8. URLのクエリパラメータが更新されること

## ソート順を降順/昇順に切り替えられること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 複数の文書が存在すること

### 手順

1. 文書管理ページにアクセスする
2. デフォルトで「降順」ボタンが表示されていること
3. 一覧が降順（新しい順）でソートされていること
4. 最初の文書のアップロード日時を記録する
5. 「降順」ボタンをクリックする
6. ボタンのラベルが「昇順」に変わること
7. 一覧が昇順（古い順）でソートされること
8. 最初の文書のアップロード日時が以前より古いこと
9. 「昇順」ボタンをクリックする
10. ボタンのラベルが「降順」に戻ること
11. 一覧が降順（新しい順）に戻ること

## ソート項目を変更できること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること

### 手順

1. 文書管理ページにアクセスする
2. デフォルトで「アップロード日時」でソートされていること
3. 「並び替え:」ドロップダウンをクリックする
4. ソート項目のリストが表示されること：
   - アップロード日時
   - ファイル名
   - サイズ
5. 「ファイル名」を選択する
6. ドロップダウンに「ファイル名」が表示されること
7. 一覧がファイル名でソートされること
8. 「サイズ」を選択する
9. 一覧がサイズでソートされること

## ページネーションで次ページに移動できること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 21件以上の文書が存在すること（2ページ以上）

### 手順

1. 文書管理ページにアクセスする
2. 1ページ目が表示されていること
3. 「1-20 / 25 件の文書」と表示されていること
4. ページネーションコントロールに以下のボタンが表示されていること：
   - 「← Previous」ボタン（無効状態）
   - 「1」ボタン（アクティブ）
   - 「2」ボタン
   - 「Next →」ボタン
5. 「Next →」ボタンをクリックする
6. 2ページ目に移動すること
7. 「21-25 / 25 件の文書」と表示されること
8. 「2」ボタンがアクティブになること
9. 「← Previous」ボタンが有効になること
10. 「Next →」ボタンが無効になること

## ページネーションで前ページに戻れること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 2ページ目を表示していること

### 手順

2. 「21-25 / 25 件の文書」と表示されていること
3. 「← Previous」ボタンをクリックする
4. 1ページ目に戻ること
5. 「1-20 / 25 件の文書」と表示されること
6. 「1」ボタンがアクティブになること
7. 「← Previous」ボタンが無効になること

## ページ番号ボタンで直接ページ移動できること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 2ページ以上存在すること

### 手順

1. 1ページ目を表示している状態から開始する
2. ページネーションコントロールで「2」ボタンをクリックする
3. 2ページ目に移動すること
4. 「21-25 / 25 件の文書」と表示されること
5. 「2」ボタンがアクティブになること
6. 「1」ボタンをクリックする
7. 1ページ目に戻ること
8. 「1-20 / 25 件の文書」と表示されること

## ページ番号がURLクエリパラメータで管理されること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること

### 手順

1. 1ページ目を表示している状態でURLを確認する
2. URLにページ番号のクエリパラメータが含まれていないこと（デフォルト）
3. 2ページ目に移動する
4. URLに `page=2` クエリパラメータが追加されること
5. ページをリロードする
6. 2ページ目が維持されていること
7. 「21-25 / 25 件の文書」と表示されること

## 20件以下の場合はページネーションが表示されないこと

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 文書が20件以下であること

### 手順

1. 文書管理ページにアクセスする
2. 「1-X / X 件の文書」と表示されること（Xは20以下）
3. ページネーションコントロールが表示されていないこと

## 文書が0件の場合にメッセージが表示されること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 文書が1件も存在しないこと

### 手順

1. 文書管理ページにアクセスする
2. 文書一覧テーブルまたはグリッドが表示されていないこと
3. 空状態メッセージが表示されること
4. メッセージに以下の内容が含まれること：
   - 文書が存在しないことを示すテキスト
   - アップロードを促すメッセージ

## リストビューでファイル種別アイコンが表示されること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 異なる種類のファイル（PDF, Excel, Word等）が存在すること

### 手順

1. 文書管理ページにリストビューでアクセスする
2. 各文書行のファイル名の前にアイコンが表示されていること
3. PDFファイルにはPDFアイコンが表示されること
4. Excelファイルには表計算アイコンが表示されること
5. Wordファイルにはドキュメントアイコンが表示されること

## グリッドビューでファイル種別が色分けされること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 異なる種類のファイルが存在すること

### 手順

1. グリッドビューに切り替える
2. 各カードの背景色がファイル種別で異なっていること
3. PDFファイルのカードが特定の背景色（例：赤系）で表示されること
4. Excelファイルのカードが特定の背景色（例：緑系）で表示されること
5. Wordファイルのカードが特定の背景色（例：青系）で表示されること

## ローディング状態でちらつきが発生しないこと

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること

### 手順

1. 文書管理ページにアクセスする
2. ページネーションで2ページ目に移動する
3. ページ遷移中に一覧が空にならないこと（前のデータが保持される）
4. 新しいデータが読み込まれてスムーズに切り替わること
5. ローディングインジケーターが表示されないこと（placeholderDataによる最適化）
6. ソート順を変更する
7. ソート中も一覧が表示され続けること
8. データがスムーズに並び替えられること
