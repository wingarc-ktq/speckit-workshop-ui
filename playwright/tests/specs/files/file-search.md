# キーワード検索

## 検索バーで文書を絞り込めること（ファイル名部分一致）

### データ

| 検索キーワード      | 期待行に含まれる文字列 |
| ------------------- | ---------------------- |
| "請求書"            | "田中商事_請求書_202401.pdf" |

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 文書一覧に請求書関連のファイルが存在すること

### 手順

1. 検索バー（プレースホルダー「ファイル名で検索...」）に `請求書` を入力する
2. 300ms待機してデバウンス後に一覧が更新されること
3. 文書一覧が `請求書` を含むファイル名だけに絞り込まれること
4. 先頭行または可視行の中に "田中商事_請求書_202401.pdf" が含まれること
5. 0件ではないことを確認する

## タグ名に対しても検索できること（タグ部分一致）

### データ

| 検索キーワード | 期待タグ |
| -------------- | -------- |
| "契約"         | 契約書   |

### 前提条件

- ログイン済み
- /documents にアクセス済み

### 手順

1. 検索バーに `契約` を入力する
2. デバウンス後、タグに「契約書」を含む文書のみが表示されること
3. 可視行のタグチップに「契約書」が含まれること

## ハイライト表示が行われること（パステル調の黄色）

### データ

| 検索キーワード | 強調対象 |
| -------------- | -------- |
| "議事録"       | ファイル名/タグ上の一致箇所 |

### 手順

1. 検索バーに `議事録` を入力する
2. デバウンス後、一覧が更新されること
3. 一致したテキストがハイライトされていること（色: #fef9c3 相当の淡い黄色）
4. リストビューでもグリッドビューでもハイライトが適用されること

## 存在しないキーワードでは0件メッセージになること

### データ

| 検索キーワード |
| -------------- |
| "no-match-xyz" |

### 手順

1. 検索バーに `no-match-xyz` を入力する
2. デバウンス後、一覧が0件になること
3. 空状態メッセージ「該当する文書が見つかりません」が表示されること

## クリア操作で検索がリセットされること

### 手順

1. 任意のキーワードを入力して一覧が絞り込まれている状態にする
2. 検索バーのクリアボタン（×）をクリックする
3. キーワードが空になり、一覧が元の件数（例: 1-20 / 25 件の文書）に戻ること

## URLクエリに検索条件が反映・永続化されること

### 前提条件

- /documents にアクセス済み

### 手順

1. 検索バーに `請求書` を入力する
2. URLを確認し、`search=請求書` クエリパラメータが付与されること
3. ブラウザをリロードする
4. 検索結果が維持された状態で再表示されること（一覧は請求書のみに絞り込み）
5. クリアするとURLの検索クエリが削除されること

## グリッドビューでも検索が適用されること

### 手順

1. 検索バーに `議事録` を入力する
2. ビューモード切替でグリッドビューにする
3. グリッドビューのカードのみが `議事録` に一致した文書に絞り込まれていること
4. カード上でもハイライト表示されること

## タグフィルタと組み合わせた検索ができること

### データ

| 検索キーワード | クリックするタグ |
| -------------- | ---------------- |
| "請求"         | 契約書            |

### 手順

1. 検索バーに `請求` を入力する
2. 「タグ」セクションのチップ「契約書」をクリックする
3. タグフィルタ + キーワードのAND条件で絞り込みされること
4. 表示された文書のタグに「契約書」が含まれ、かつファイル名/タグに `請求` を含むこと

## 日付範囲フィルタと組み合わせた検索ができること

### データ

| 検索キーワード | 開始日     | 終了日     |
| -------------- | ---------- | ---------- |
| "請求"         | 2024/01/01 | 2024/01/31 |

### 手順

1. 検索バーに `請求` を入力する
2. 「アップロード日時」で開始日に `2024/01/01`、終了日に `2024/01/31` を入力する
3. 範囲に一致する文書のみが表示されること
4. 一覧の日付が指定範囲内に収まっていること

## 部分一致・大文字小文字の違いを許容すること

### データ

| 入力 | 期待 |
| ---- | ---- |
| "pdf" | 拡張子やファイル名に`pdf`を含むものがヒット |
| "PDF" | 同様にヒット（ケース非依存） |

### 手順

1. 検索バーに `pdf` を入力する
2. 結果が表示されること
3. `PDF` と入力しても同様の結果が得られること

## 検索中も一覧がちらつかないこと（placeholderData）

### 手順

1. 連続して別のキーワードを入力する（例: `請求書` → `契約書`）
2. デバウンス後に結果が切り替わるが、切り替え中に一覧が空表示にならないこと
3. スムーズに新しい結果へ更新されること

## ナビゲーション後も検索状態が保持されること

### 手順

1. `search=請求書` が付いた状態で「ダッシュボード」に一度移動する
2. 再度「文書管理」に戻る
3. 検索状態（請求書）が保持されたままで一覧が絞り込まれていること
