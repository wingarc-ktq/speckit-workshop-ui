# ファイルアップロード

## アップロードダイアログが表示されること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること

### 手順

1. 文書管理ページの「アップロード」ボタンをクリックする
2. 「文書をアップロード」ダイアログが表示されること
3. ダイアログに以下の要素が含まれていること：
   - タイトル：「文書をアップロード」
   - ファイルドロップエリア（「ファイルをドラッグ&ドロップ、または」のテキスト）
   - 「ファイルを選択」ボタン
   - 対応形式の説明：「対応形式: PDF, Word, Excel, 画像 (最大10MB、最大20ファイル)」
   - タグ選択セクション（「タグを選択」の見出し）
   - タグチップ（完了、契約書、請求書、未処理、処理中、議事録）
   - 「キャンセル」ボタン
   - 「アップロード」ボタン（初期状態は無効）

## ファイルを選択してアップロードできること

### データ

| ファイル名         | サイズ | タグ         |
| ------------------ | ------ | ------------ |
| test-document.txt  | 22 B   | 完了、契約書 |

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- アップロード対象のファイルが存在すること

### 手順

1. 「アップロード」ボタンをクリックする
2. 「文書をアップロード」ダイアログが表示されること
3. 「ファイルを選択」ボタンをクリックする
4. ファイル選択ダイアログで `test-document.txt` を選択する
5. 選択したファイルが表示されること
6. 「完了」タグをクリックして選択する
7. 「契約書」タグをクリックして選択する
8. 選択したタグが強調表示されること
9. 「アップロード」ボタンが有効になること
10. 「アップロード」ボタンをクリックする
11. ダイアログが閉じること
12. 文書一覧に新しいファイルが追加されること
13. アップロードしたファイルに選択したタグが表示されること

### データ

2. 「文書をアップロード」ダイアログが表示されること
3. ファイルをドロップエリアにドラッグ&ドロップする
4. ドロップしたファイルが表示されること
5. 「請求書」タグをクリックして選択する
6. 「アップロード」ボタンが有効になること
7. 「アップロード」ボタンをクリックする
8. ダイアログが閉じること

## 複数ファイルを同時にアップロードできること

### データ

| ファイル名      | サイズ | タグ       |
| --------------- | ------ | ---------- |
| document1.pdf   | 500 KB | 完了       |
| document2.docx  | 300 KB | 完了       |
| document3.xlsx  | 200 KB | 完了       |

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- アップロード対象の複数ファイルが存在すること

### 手順

1. 「アップロード」ボタンをクリックする
2. 「文書をアップロード」ダイアログが表示されること
3. 「ファイルを選択」ボタンをクリックする
4. ファイル選択ダイアログで複数ファイル（document1.pdf, document2.docx, document3.xlsx）を選択する
5. 選択した3つのファイルがすべて表示されること
6. 「完了」タグをクリックして選択する
7. 「アップロード」ボタンが有効になること
8. 「アップロード」ボタンをクリックする
9. ダイアログが閉じること
10. 文書一覧に3つの新しいファイルがすべて追加されること

| ファイル名           | サイズ  | 期待されるエラー                      |
| -------------------- | ------- | ------------------------------------- |
| large-file.pdf       | 15 MB   | ファイルサイズは10MB以下にしてください |

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 10MBを超えるファイルが存在すること

### 手順

1. 「アップロード」ボタンをクリックする
2. 「文書をアップロード」ダイアログが表示されること
3. 「ファイルを選択」ボタンをクリックする
4. ファイル選択ダイアログで10MBを超えるファイル（large-file.pdf）を選択する
5. エラーメッセージ「ファイルサイズは10MB以下にしてください」が表示されること
6. ファイルが選択されていない状態であること
7. 「アップロード」ボタンが無効のままであること

## タグを選択せずにアップロードできること

### データ

| ファイル名         | サイズ | タグ |
| ------------------ | ------ | ---- |
| no-tag-file.pdf    | 1 MB   | なし |

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること

### 手順

1. 「アップロード」ボタンをクリックする
2. 「文書をアップロード」ダイアログが表示されること
3. 「ファイルを選択」ボタンをクリックする
4. ファイル選択ダイアログで `no-tag-file.pdf` を選択する
5. タグを選択せずに「アップロード」ボタンが有効になること
6. 「アップロード」ボタンをクリックする
7. ダイアログが閉じること
8. 文書一覧に新しいファイルが追加されること
9. アップロードしたファイルにタグが表示されないこと

## キャンセルボタンでダイアログを閉じられること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること

### 手順

1. 「アップロード」ボタンをクリックする
2. 「文書をアップロード」ダイアログが表示されること
3. 「ファイルを選択」ボタンをクリックする
4. ファイル選択ダイアログでファイルを選択する
5. 選択したファイルが表示されること
6. 「キャンセル」ボタンをクリックする
7. ダイアログが閉じること
8. 文書一覧に新しいファイルが追加されていないこと（アップロードがキャンセルされていること）

## アップロード後にキャッシュが無効化されること

### 前提条件

- ログイン済みの状態であること
- 文書管理ページ（/documents）にアクセスしていること
- 文書一覧が表示されていること

### 手順

1. 現在の文書一覧の件数を記録する
2. 「アップロード」ボタンをクリックする
3. ファイルを選択してアップロードする
4. ダイアログが閉じること
5. 文書一覧が自動的に更新されること（リロード不要）
6. 文書一覧の件数が1件増加していること
7. 最新のファイルが一覧に表示されること
