# コマンドパレット

## 注記

- 対象URLはログイン後のマイファイル画面（`/`）。コマンドパレットは `AppLayout` に配置されており、アプリ内のどの画面からでも開ける想定である
- `⌘K`（Mac）/ `Ctrl+K`（Win/Linux）で開く。本仕様書・実装ではE2E実行環境（Linux）に合わせて `Control+K` を用いる
- 検索は既存の文書一覧（`file-list.md`）と同じ300msのデバウンスを持つ
- 候補選択後の `Enter` は既存のファイル詳細ダイアログを開く（`FileDetailDialog` を再利用）が、本仕様書ではPhase 3で挙げられた3ケース（開閉・絞り込み）に絞り、詳細ダイアログ連携の検証は対象外とする

## Ctrl+K でコマンドパレットが開くこと

### データ

| ファイル名           |
| --------------------- |
| 田中商事_請求書.pdf   |
| 佐藤建設_契約書.pdf   |

### 前提条件

- テスト実行前に上記2件の文書がアップロードされていること

### 手順

1. 文書一覧ページ（`/`）にアクセスする
2. `Control+K` を押す
3. `data-testid="commandPalette"` のダイアログが表示されること
4. `data-testid="commandPaletteInput"` の入力欄にフォーカスが当たっていること
5. `data-testid="commandPaletteItem"` の候補が2件（アップロードした2件分）表示されること

### 事後処理

- ページをリロードし、MSWがインメモリで保持しているモックファイルデータをリセットする

## キーワードを入力すると候補が絞り込まれること

### データ

| ファイル名           | 検索キーワード |
| --------------------- | -------------- |
| 田中商事_請求書.pdf   | 田中商事       |
| 佐藤建設_契約書.pdf   |                |

### 前提条件

- テスト実行前に上記2件の文書がアップロードされていること
- `Control+K` でコマンドパレットが開いている状態であること

### 手順

1. `data-testid="commandPaletteInput"` に「田中商事」と入力する
2. 300ms のデバウンス処理が完了するまで待機する
3. `data-testid="commandPaletteItem"` の候補が1件のみ表示され、「田中商事_請求書.pdf」であること
4. 「佐藤建設_契約書.pdf」は候補に表示されないこと

### 事後処理

- ページをリロードし、MSWがインメモリで保持しているモックファイルデータをリセットする

## Esc でコマンドパレットが閉じること

### データ

| ファイル名         |
| ------------------- |
| 田中商事_請求書.pdf |

### 前提条件

- テスト実行前に文書が1件以上アップロードされていること
- `Control+K` でコマンドパレットが開いている状態であること

### 手順

1. `Escape` キーを押す
2. `data-testid="commandPalette"` のダイアログが表示されなくなること

### 事後処理

- ページをリロードし、MSWがインメモリで保持しているモックファイルデータをリセットする
